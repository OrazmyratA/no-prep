Google Drive test

Checks whether books can work from Google Drive on this device. Use a test Google account. Everything goes in one folder, "No-Prep test (safe to delete)". Step 9 removes it.

1. Sign in Not run

Tick the Google Drive box if Google asks.

2. Save and read a small file Not run

3. See files from the desktop app Not run

Only meaningful if this account linked Drive backup in the desktop app.

4. PDF page Not run

5. Video Not run

After choosing, tap Play on each video that appears, then drag it to the middle.

6. Your biggest book Not run

Choose an exported book folder, or a .noprepbook or .zip file (not .rar). It uploads one file at a time. Keep this page open. If the page reloads by itself, it will say where it stopped.

7. Shared book, viewer side Not run

Owner's account: type the viewer's Google email and share the small test file from step 2, with downloads turned off for viewers.

Viewer's account: open this page, sign in, and pick what was shared.

8. This device's storage Not run

9. Clean up Not run

Moves the test folder to the Drive bin and turns off the video helper.

Results

Copy these and send them back. They contain no passwords, sign-in keys or email addresses.
